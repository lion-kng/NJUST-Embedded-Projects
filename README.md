# STM32 嵌入式开发项目集

NJUST 22级计算机嵌入式作业和实验代码

## 项目列表

### GPIO 相关
- `01_first` - 第一个 STM32 项目
- `922106840122_gpio` - GPIO 基础实验
- `922106840122_gpio_intr` - GPIO 中断实验
- `922106840146_gpio_intr` - GPIO 中断实验（变体）

### 定时器相关
- `922106840122_time6_clock` - TIM6 时钟实验
- `922106840146_tim6_clock` - TIM6 时钟实验
- `922106840146_tim6_clock1` - TIM6 时钟实验（变体）

### 通信接口
- `922106840122_I2CICM` - I2C ICM 传感器实验
- `922106840122_SPI` - SPI 通信实验

### 外设控制
- `922106840122_KEY` - 按键实验
- `922106840122_LCD` - LCD 显示实验

### 其他
- `test` - 测试项目

## 开发环境

- IDE: Keil MDK-ARM V5
- MCU: STM32F4 系列
- HAL 库: STM32Cube HAL

## 编译说明

每个项目目录下的 `MDK-ARM` 文件夹包含 Keil 工程文件（`.uvprojx`），使用 Keil MDK 打开即可编译。
